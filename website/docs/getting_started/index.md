# Getting Started

## Recommended path

1. [Choose an enforcer](../guides/enforcers/index.md) for the behavior you need to control.
2. [Install vArmor](installation.md) after checking your nodes and runtime.
3. [Write and verify a policy](../guides/policies_and_rules/writing_policies.md) in a dedicated namespace.
4. Use [Usage Instructions](usage_instructions.md) for status, logs and lifecycle operations.

Keep [Interface Specification](interface_specification.md) nearby for field definitions, and use [Metrics](metrics.md) to monitor the components.
