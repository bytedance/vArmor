# 开始使用

## 推荐顺序

1. 根据要控制的行为[选择执行器](../guides/enforcers/index.md)。
2. 核对节点和运行时后[安装 vArmor](installation.md)。
3. 在专属 namespace [编写并验证策略](../guides/policies_and_rules/writing_policies.md)。
4. 按[使用说明](usage_instructions.md)查看状态、日志和生命周期操作。

字段定义见[接口说明](interface_specification.md)，组件监控见[指标](metrics.md)。
